# Finance Calendar for ChatGPT

Find economic releases, central-bank decisions, exchange holidays and covered crypto events through your linked Finance Calendar account. Read recorded dates, available figures and original publisher evidence in one conversation.

## Connect your account

1. Add Finance Calendar using ChatGPT’s supported plugin controls.
2. Choose Connect when ChatGPT requests account linking.
3. Sign in on **www.financecalendar.com**, review the read-only permission and approve the connection.
4. Return to ChatGPT and ask a calendar question.

Use your existing verified Finance Calendar account with eligible hosted access. The connection uses read-only `calendar:read`; optional `offline_access` lets ChatGPT renew it. Requests share the account’s existing API allowance. Installing or linking this plugin does not create a subscription or change account permissions. Never paste passwords, API keys or OAuth tokens into a conversation.

## Example questions

- Which UK and US releases are scheduled this week? Include original sources.
- When is the next US CPI release? Is its exact time verified?
- What are the upcoming NYSE holidays and early closes?

## Read results accurately

Coverage follows supported publishers and announced horizons. Exact times, approximate windows, missing values, freshness and recorded numerical evidence remain distinct. A missing figure is not zero. Recorded history does not establish an unobserved original first print. Partial overview responses are labelled and include information for continuation. One question can require several metered reads.

The plugin has 14 bounded, read-only MCP tools. It cannot place trades, transfer money, modify records, change subscriptions, create account keys or initiate checkout. Separate local clients and REST routes can have capabilities beyond this hosted plugin; this package does not install or execute them.

## Privacy and support

Sign-in and consent happen on Finance Calendar. The client’s private connection store manages OAuth credentials. Finance Calendar receives the authorized account/client references and the tool arguments needed for the requested data, rather than whole conversations or unrelated files. Review or revoke access in your Finance Calendar connected-assistant settings. Revocation stops that connection without cancelling the account or affecting other keys.
